# pixar-3d-animated-scene
A Pixar-inspired 3D animated short scene with expressive character animation, cinematic camera motion, and emotional storytelling using React Three Fiber, GSAP, and Blender models.

## Instagram carousel

Slide 01 of the "6 hooks that stop the scroll" carousel lives in `output/slide-01.png`
(1080x1350). It is composed in code from a cinematic photo plate plus Anton / Inter type —
see `carousel/SLIDE-01.md` for the layout spec, palette and rebuild command
(`python3 scripts/build_slide.py`).
